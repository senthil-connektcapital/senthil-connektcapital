# senthil-connektcapital

OpenMontage × Agent SDK × OpenRouter comparison lives in [`openmontage-openrouter-sdk/`](openmontage-openrouter-sdk/README.md).

That package checks whether the [OpenMontage](https://github.com/calesthio/OpenMontage) skill set can run from Claude Agent SDK / Codex SDK (not the interactive CLI) and whether one OpenRouter key can replace the usual video-vendor keychain (including HeyGen, Kling, Veo, Seedance, and others).
